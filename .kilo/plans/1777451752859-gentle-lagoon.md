# Test Plan: 1080p Video Download with FFmpeg Merging

## Objective
Create and execute a test case for downloading YouTube videos in 1080p resolution, ensuring proper integration between yt-dlp and ffmpeg for video/audio merging.

## Analysis
Based on the logs and code review:
- The system successfully finds yt-dlp and ffmpeg executables
- Video info fetching works correctly (31 formats found, 9 audio, 19 video)
- Download process initiates but fails with exit code 1
- The yt-dlp command includes proper ffmpeg post-processing args: `-c:v libx264 -preset medium -crf 23 -c:a aac -b:a 128k`

## Current Issue
The download fails with yt-dlp exit code 1, likely due to:
1. Format selection issues with 1080p requirement
2. Potential ffmpeg compatibility problems
3. Output path formatting issues (special characters in title)

## Test Strategy
1. Create a dedicated test script that:
   - Connects to the WebSocket for progress monitoring
   - Starts a download with 1080p MP4 format
   - Waits for completion with appropriate timeout
   - Verifies the downloaded file exists and is valid
   - Cleans up test files afterward

2. Key test elements:
   - Use the same URL from logs: https://www.youtube.com/watch?v=XTzzvT9BR34
   - Test 1080p MP4 format selection
   - Verify ffmpeg is properly invoked for merging
   - Check output file properties (size, format, etc.)

## Implementation Plan
1. Create test script: `web/test_1080p_download.js`
2. Implement WebSocket connection for real-time progress
3. Use existing download API endpoints
4. Add file verification after download completion
5. Include proper error handling and cleanup

## Success Criteria
- Download initiates without errors
- Progress updates are received via WebSocket
- Download completes with status 'completed'
- Output file exists in expected location
- File is valid MP4 with reasonable size (>0 bytes)
- FFmpeg merging is confirmed through file properties
